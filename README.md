# Codex 豆包桌宠


一个为 Codex 打造的 3D Q 版女孩桌面宠物。她会眨眼、招手、跳跃、等待输入，并在执行任务时努力敲击键盘。

</div>

## 快速安装

通过 [release](https://github.com/nagi-hikaru/doubao/releases) 下载压缩包并解压到codex的pet目录下，或者在 [petdex](https://petdex.dev/pets/doubao-8) 上安装。
